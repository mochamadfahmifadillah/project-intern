# Project Intern

Admin dashboard untuk kebutuhan project magang dengan sistem **Authentication** dan **Role-Based Access Control (RBAC)**.

## Tech Stack

* Laravel
* React + TypeScript
* Tailwind CSS
* PostgreSQL
* Laravel Sanctum
* Axios

## Features

* Authentication (Login, Register, Logout)
* User Management
* Role Management
* Permission Management
* Role-Based Access Control (RBAC)
* User & Role Management
* Role & Permission Management
* API Authentication menggunakan Laravel Sanctum

## Role & Permission

Sistem menggunakan role dan permission untuk mengatur hak akses pengguna.

Role yang tersedia:

* Super Admin
* Admin
* Staff

Permission meliputi:

* Users
* Roles
* Permissions

Setiap fitur memiliki permission untuk **View, Create, Edit, dan Delete** sesuai kebutuhan akses.
